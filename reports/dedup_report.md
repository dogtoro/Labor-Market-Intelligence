# Dedup report

Generated by `src/clean/dedup.py`.

## Logic

A later row is marked duplicate when:

1. company matches after case/whitespace normalization;
2. title similarity (SequenceMatcher) is **>= 0.85**; and
3. when both dates exist, `posted_date` differs by **<= 7 days**.

If either date is missing, the decision uses company + title only. Duplicate rows are removed from `jobs_clean.parquet`; retained rows have `is_duplicate = False`.
